Mint-Y theme amber variation with a classic touch
=================================================

This adds a variation to Mint-Y in amber color and changes some stuff around for a more classic UI

* Removed rounded corners
* Removed window drop shadows
* Added amber 1px border around focused window
* Removed Mint-X related stuff entirely (as it's not the focus of this)

Dependencies for building (unchanged from original):
* optipng
* pysassc

Building & installing
=====================

1. run `./install.sh` (builds the theme if needed and copies it to ~/.themes)
2. enjoy

Use `./install.sh -b` to force a rebuild, or set `THEMES_DIR` to install somewhere else.
